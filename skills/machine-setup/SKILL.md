# Dotfiles

All of the user's configuration lives in the git repository at `~/git/dot`.

## Always start here

Before doing anything else, read `~/git/dot/CLAUDE.md`. It contains the
repo's own instructions (layout, how files are linked or installed, scripts,
conventions).
